# Power BI Sales Analytics Dashboard

## Overview
This project is an interactive Sales Analytics Dashboard built using Power BI to analyze sales performance and customer behavior.

## Features
- Total Sales, Customers & Transactions
- Monthly Sales Trend
- Sales by Product Category
- Customer Analysis by Gender and Age Group
- Interactive Slicers

## Tools Used
- Power BI
- Power Query
- DAX

## Skills Demonstrated
- Data Cleaning
- Data Visualization
- Dashboard Design
- Business Intelligence
